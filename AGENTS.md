# Agent contract

This is a public, documentation-only brand toolkit. Read README.md, docs/brand-system-standard.md and ROADMAP.md first. English source documents; user-facing summaries may follow the user's language.

Preserve client privacy: no client assets, contacts, private paths, raw conversations or internal audit evidence in this repository. Link public primary references rather than redistributing their artwork. Keep reusable rules in the standard and the shared skill; do not fork per-platform behavior.

Use VERIFIED, MISSING and UNKNOWN with evidence. No automatic license selection, publication, external sends or live brand replacement. Run `python3 scripts/check.py` after edits. That is a document check, not a security or visual certification. Before release obtain independent review and state any unchecked requirements.
